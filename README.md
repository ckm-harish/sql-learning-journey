# SQL Learning Journey

MySQL practice repository documenting my progress from SQL fundamentals toward data analytics.

## Repository structure

- `01_SQL_Fundamentals/` — reserved for foundational SQL topics such as DDL, DML, DQL and DCL.
- `02_SQL_Conditions_and_Operators/` — 25th and 26th homework files covering filtering and conditions.
- `03_SQL_Null_and_Pattern_Matching/` — 28th homework covering NULL checks and `LIKE` / `NOT LIKE`.
- `04_SQL_Functions/` — add as you organise function practice.
- `05_SQL_Joins/` — add when you organise join practice.
- `06_SQL_Subqueries/` — add your current subquery practice here.
- `07_Interview_Questions/` — add interview-focused exercises.
- `08_SQL_Projects/` — add complete, documented SQL projects.
